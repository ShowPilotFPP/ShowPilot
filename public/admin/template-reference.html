How placeholders work

Write a placeholder in curly braces anywhere in your template's HTML and ShowPilot replaces it when the page loads, then keeps it up to date while visitors are on the page (no refresh needed). Names are case-sensitive.

<h2>Now playing: {NOW_PLAYING}</h2>
<div {jukebox-dynamic-container}>
  <div class="jukebox_table">{PLAYLISTS}</div>
</div>
Placeholders are replaced everywhere, even inside HTML comments. To mention one in a comment, write it without the braces (e.g. NOW_PLAYING).

Each one becomes a small element you can style; the class or data attribute in the second column is what ShowPilot puts on it.

Show / hide sections

Put one of these inside an opening tag. ShowPilot shows that element only when it applies, and switches it live (e.g. when you change from Voting to Jukebox). Hidden elements get the hidden attribute.

<div class="intro" {after-hours-message}>The show starts at 6 PM!</div>
Write in the tagBecomesShown when
{jukebox-dynamic-container} RFdata-showpilot-container="jukebox"Jukebox mode.
{playlist-standard-dynamic-container} RFsame as jukeboxJukebox mode (older Remote Falcon name).
{playlist-voting-dynamic-container} RFdata-showpilot-container="voting"Voting mode.
{race-dynamic-container} SPdata-showpilot-container="race"Race mode.
{location-code-dynamic-container} RFdata-showpilot-container="locationcode"An access code is required.
{after-hours-message} RFdata-showpilot-container="afterhours"Viewer control is off (outside show hours).
{message-dynamic-container} SPdata-showpilot-container="messages"Visitor messages are open.

Put {PLAYLISTS} inside a Voting and a Jukebox section and each gets the right kind of rows. To hide other parts while the after-hours message shows:

body:has([data-showpilot-container="afterhours"]:not([hidden])) .now-playing-card { display: none; }

Song list markup

What {PLAYLISTS} puts on the page. The classes match Remote Falcon's, so Remote Falcon CSS keeps working; ShowPilot adds a few of its own.

Jukebox row

<div class="jukebox-list sequence-item" data-seq="File name" onclick="ShowPilotRequest('File name')">
  <div>
    <img class="sequence-image" src="…cover…">          <!-- only when the song has a cover -->
    <span class="sequence-name">Display Name</span>
    <span class="sequence-badge">New</span>            <!-- only with a badge -->
    <div class="jukebox-list-artist sequence-artist">Artist</div>
    <span class="sequence-requests"></span>
  </div>
</div>

Voting row

Two cells side by side with no row wrapper (Remote Falcon's layout), so a two-column grid on the container pairs them up.

<div class="cell-vote-playlist sequence-item" data-seq="File name" onclick="ShowPilotVote('File name')">
  <div>
    <img class="sequence-image" src="…">
    <span class="sequence-name">Display Name</span>
    <div class="cell-vote-playlist-artist sequence-artist">Artist</div>
    <span class="sequence-votes">3</span>              <!-- hidden by default -->
  </div>
</div>
<div class="cell-vote" onclick="ShowPilotVote('File name')">3</div>

.sequence-item SPevery song rowOne selector for both modes.
.jukebox-list, .cell-vote-playlist, .cell-vote RFrows / vote count cellThe vote count cell also casts the vote when tapped.
.sequence-image, .sequence-name, .sequence-artist RFinside a rowImages come with width="40" as a hint; your CSS wins. The artist line is empty when there's no artist (use :empty).

.sequence-category-header SPcategory headingsShown above each group when songs have categories (and headings are on in Sequences → Categories). Spans the full width in grid and flex lists.

Example: your own cooldown look

.showpilot-cooldown { opacity: .5; filter: none; }
.sequence-cooldown { color: #b3b3b3; font-size: 12px; }
/* or hide the note and use the attribute instead */
.sequence-cooldown { display: none; }
.showpilot-cooldown .sequence-name::after { content: " · back " attr(data-cooldown); }

The default cooldown and badge styles have no specificity, so any rule of yours wins.

Race mode

In Race mode {PLAYLISTS} becomes tap buttons with a bar per song: .race-row, .race-cover, .race-row-info, .race-song-name, .race-song-artist, .race-bar-track, .race-bar-fill, .race-tap-btn, .race-tap-count, plus .race-instructions and .race-empty. The winner is announced in #showpilot-race-winner-overlay. Templates don't need a race section; {race-dynamic-container} is there if you want race-only content.

Pop-up messages

Add an element with one of these IDs (usually hidden with style="display:none") and ShowPilot shows it for a few seconds at the right moment; tapping it closes it. If a specific one is missing, ShowPilot shows #requestFailed with its own wording, so #requestSuccessful and #requestFailed cover everything.

IDShown when
#requestSuccessful RFA request was added (and a vote, if there's no #voteSuccessful).
#voteSuccessful SPA vote was counted.
#requestFailed RFAnything else went wrong, with ShowPilot's explanation when there's no matching element below.
#requestPlaying RFThat song is already in the queue.
#queueFull RFThe queue is full.
#alreadyVoted RFThe visitor already voted this round.
#invalidLocation RFThe visitor isn't close enough to the show (or location was blocked).
#invalidLocationCode SPWrong access code.
#songPlaying SPThat song is playing right now.
#songNextUp SPThat song is already up next.
#songCooldown SPThat song is cooling down. Any element inside with data-showpilot-cooldown-text gets "after 3 more songs" / "in about 12 minutes".
 
<div id="songCooldown" class="toast" style="display:none">
  Hang on! That one comes back <span data-showpilot-cooldown-text></span>.
</div>

The voting-round winner announcement is #showpilot-winner-toast; restyle it with the --showpilot-toast-* variables.

Progress bar

<div class="sp-progress sp-progress--inline" data-showpilot-progress role="progressbar">
  <div class="sp-progress-track"><div class="sp-progress-fill"></div></div>
  <span class="sp-progress-time">2:41</span>
</div>

.sp-progress--idle is added when nothing is playing or the song's length is unknown. The fill color comes from Settings (or --sp-progress-color); it's set inline, so override it with !important. Where the time sits (left/right) is a setting too.

Visitor messages

{MESSAGE_BOX} gives form.sp-message-box[data-showpilot-message-box], hidden while messages are closed, so you can show something else instead:

.msg-closed { display: none; }
.panel:has(form[data-showpilot-message-box][hidden]) .msg-closed { display: block; }

{MESSAGE_WALL} gives section.sp-message-wall[data-showpilot-message-wall] with data-style = cards, bubbles or ticker. Both carry data-sp-theme = dark or light (the Box style setting). Inner classes start with sp-message- and sp-wall-. Your page's own CSS is kept away from them, so set the colors with the --sp-message-* variables.

Listen on Phone

The floating headphones button is #of-listen-btn; its colors come from Settings → Listen-on-Phone (or --sp-launcher-bg / --sp-launcher-fg).

AttributeDoes
data-sp-listen-iconPut on an empty <span> in your help text and ShowPilot fills it with a copy of the Listen button's icon and colors, so instructions always match the real button.
data-showpilot-sync-helpThe element is shown only while "sync help" is switched on in the admin (use it for "music out of sync?" tips).

Set these on :root (or any parent) to restyle ShowPilot's own parts to match your page.

JavaScript

Use these in onclick if you build your own buttons. Pass the song's file name (the data-seq value), not its display name.

CallDoes
ShowPilotRequest('File name')Requests the song (Jukebox). Also available as RemoteFalconRequest, OpenFalconRequest and request.
ShowPilotVote('File name')Votes for the song (Voting). Also RemoteFalconVote, OpenFalconVote and vote.

Both handle the access code, location check and pop-up messages for you.

Tips

  • Global CSS (Viewer Page → Global CSS) is added to every template, handy for one rule you want everywhere.
  • Hand-built pages can be rearranged without code in the template editor's Sections tab.
  • Remote Falcon templates work as they are. To bring one up to date with the extras on this page, use the converter at showpilot.dev/convert.
  • The preview in the template editor uses your real songs and settings, so states like cooldowns and badges show there as they will on the live page.
