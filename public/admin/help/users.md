# Users

The people who can sign in to this admin panel. Add an account for each person who helps run your show, so nobody has to share a password.

> **Important:** Every user has full access. There are no roles or limited accounts: anyone in this list can change any setting, edit the viewer page and add or delete other users. Only add people you trust with the whole show.

## The user list

Each account shows its username, when it last signed in, and **30-day session** if it chose to stay signed in. Tags next to the name:

- **YOU**: the account you're signed in with.
- **DISABLED**: the account exists but can't sign in.
- **MUST CHANGE PW**: they'll have to pick a new password the next time they sign in.

## + Add User

Opens a form with:

- **Username**: 2 to 32 characters, using letters, digits, `_`, `.` and `-`. Each username must be unique.
- **Initial password**: at least 4 characters.
- **Force password change on first login**: on by default. Leave it on so the new user replaces the password you gave them with one only they know.

## Editing an account

Each user has these buttons:

| Button | What it does |
|---|---|
| **Edit** | Change the **Username**, or tick **Force password change on next login**. |
| **Reset PW** | Set a new password for someone who has forgotten theirs. They must change it the next time they sign in. |
| **Disable** / **Enable** | A disabled user keeps their account but can't sign in, and is signed out on their next action if they're signed in now. Good for a helper who only works during the season. |
| **Delete** | Removes the account for good. Asks first and can't be undone. |

ShowPilot stops you locking everyone out: you can't disable or delete your own account, and if there's only one account, it can't be deleted or disabled.

> **Tip:** Prefer **Disable** over **Delete** for people who help every year. Next season, click **Enable** and they're back, with the same username.

## Change My Password

Changes the password of the account you're signed in with. Enter your **Current password**, then the **New password** (at least 4 characters) twice and click **Change Password**.

> **Tip:** Use a longer password than the minimum, especially if your admin panel can be reached from the internet. For signing in and forgotten passwords, see [Signing in](help:signing-in).
