# Settings › Cockpit

Cockpit is a big-button show remote made for a tablet at your booth or garage. This tab is where you open it and change what it shows. For a full guide to using it, see [Cockpit (tablet remote)](help:cockpit).

## What Cockpit shows

You choose exactly which controls are on it: switches, viewer modes, actions, song categories, status readouts and live panels. Each control is a tile. You can add tiles, drag them into a different order, make them bigger or smaller, and remove the ones you don't need.

Your layout is saved to your admin account, not to the tablet. Sign in on any tablet and you get the same Cockpit. Each admin user has their own layout.

## Customize Cockpit

Opens Cockpit ready for editing. Add, move, resize and remove tiles; each change is saved as you make it. Press **Done** when you're finished. **Reset to default** puts back the standard layout.

## Open Cockpit

Opens Cockpit to use it as a remote. To change the layout later from Cockpit itself, use its **Edit layout** button.

> **Tip:** On the tablet, add Cockpit to the home screen. It then opens full-screen, like an app, without the browser's address bar.
